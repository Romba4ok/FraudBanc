# Задачи: поэтапное развитие frontend Risk Ledger

Документ является планом реализации требований из `frontend-spec.md`. Задачи выполняются строго по порядку. Следующая задача начинается только после прохождения проверки предыдущей.

Общие правила для всех задач:

- не менять расчёты модели и правила preprocessing без отдельного требования;
- сохранять локальную обработку данных без внешних сервисов;
- не удалять существующий рабочий сценарий до появления проверенной замены;
- наиболее рискованные записи всегда показывать первыми;
- после каждого этапа запускать затронутые frontend-тесты, lint и production build;
- фактический результат и найденные ограничения записывать в соответствующую задачу.
